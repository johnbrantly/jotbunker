# Scratchpads

Six freeform text areas for thinking in progress. Like a notepad.

## How it works

The Scratchpad tab shows one text area at a time. Switch between six categories using the category strip. Default categories: CLIENT, SCHOOL, CREATE, DREAM, TEMP, TBD. Each category holds a single block of freeform text.

Type whatever you want. No structure, no formatting, no character limit. Start a brainstorm on your computer and pick it up on your phone, or the other way around.

On the computer, right-click a category pill to rename it inline (no need to open settings).

### Header menu

| Platform | Menu item | Action |
|---|---|---|
| Phone | CLEAR THIS SCRATCHPAD | Clears the text in the active category (asks first) |
| Computer | SAVE → {tag} | Saves the current scratchpad to the selected tag (only when a tag is selected) |
| Computer | CLEAR THIS SCRATCHPAD | Clears the text in the active category (asks first) |

## Sync behavior

Scratchpad text syncs both directions during a regular sync. If you only edited one side since the last sync, that side's text wins for that scratchpad. If you edited the same scratchpad on both sides, the most recent change wins. In the very rare case where both sides changed it at the exact same moment, the app asks which version to keep.

Category renames sync the same way as [Lists](lists.md) categories.

## Font size

Scratchpad has its own font size setting, independent of lists. Adjust it in settings.
